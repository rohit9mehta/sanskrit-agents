How the commentary settled it

Where the verse alone is ambiguous, the reading follows Vyāsa's commentary; the deciding lines are quoted below each decision.
Translate tā eva as “these very [four attainments],” not as an independent feminine plural with no supplied referent.
→ tāḥ refers to the four samāpattis previously taught.
ys [1]tāś catasraḥ samāpattayo bahirvastubījā iti samādhir api sabījaḥ.
Those four attainments, having external objects as their seed, therefore the samādhi too is with seed.
Take bīja technically as the objective support or germ of these samāpattis, not as a literal plant-seed; render “seeded concentration (sabīja samādhi).”
→ sabījaḥ means “seeded,” i.e. possessing an external-object seed.
ys [1]bahirvastubījā iti samādhir api sabījaḥ
because they have external objects as seed, the samādhi too is seeded
ys [2]tatra sthūle 'rthe savitarko nirvitarkaḥ, sūkṣme 'rthe savicāro nirvicāra iti caturdhopasaṃkhyātaḥ samādhir iti.
There, with a gross object: savitarka and nirvitarka; with a subtle object: savicāra and nirvicāra—thus samādhi is counted fourfold.
Although tāḥ is feminine plural, samādhiḥ is singular masculine because the sūtra identifies the four samāpattis collectively as the seeded form of samādhi.
→ The singular samādhiḥ is a class-name comprising those four attainments.
ys [1]tāś catasraḥ samāpattayo ... samādhir api sabījaḥ
those four samāpattis ... the samādhi too is seeded
ys [2]caturdhopasaṃkhyātaḥ samādhir iti
samādhi is counted fourfold
