## Translation

> As a man, having cast off worn-out garments,
takes up other, new ones,
so too the embodied one (dehī), the self (ātman), remaining unchanged,
having cast off worn-out bodies,
goes to other, new ones.

## One-shot delta

- A commentary-blind rendering might translate dehī merely as ‘the embodied person’ and miss Śaṅkara’s explicit identification with the self (ātman) and the point that it remains unchanged.
- It might take aparāṇi as ‘later’ rather than Śaṅkara’s anyāni, ‘other’.

- It might fail to keep the second jīrṇāni with the abandoned bodies, not with the other new bodies.
